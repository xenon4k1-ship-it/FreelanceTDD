# FreelanceTDD

Проект ЛР№5 по ТП.
Демонстрирует переходы между состояниями проекта и проверяет их с помощью NUnit.

## Запуск демонстрации

`dotnet run --project Freelance.Demo/Freelance.Demo.csproj`

## Запуск тестов

`dotnet test Freelance.Tests/Freelance.Tests.csproj`

## Структура проекта

- `Freelance.Core` — логика переходов между состояниями проекта.
- `Freelance.Demo` — консольная демонстрация.
- `Freelance.Tests` — модульные тесты NUnit.
